Do not install or upgrade to package versions released within the last 7 days. Only use versions that are at least 7 days old.

**Why:** User wants stability — avoids newly-released packages that may have bugs or breaking changes.

**How to apply:** Before installing or upgrading any npm/pip/brew package, check the release date. If the latest version is newer than 7 days, use the previous stable version instead.
