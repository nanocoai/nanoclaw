================================================================================
Structured-log shape
================================================================================
Every web-fetch ok=false (or rc≠0) tick emits ONE line to stderr:

  {
    "event":            "paris-rental-watch.pap.fetch.failure",
    "ts":               "<ISO 8601 UTC>",
    "consec_failures":  <int — post-increment>,
    "threshold":        <int — PAP_FAILURE_THRESHOLD, default 3>,
    "reason":           "<truncated 300ch, newlines collapsed>",
    "will_alert":       <bool — true iff this tick will fire Discord>
  }

Ratings:
  * `event` is unique → `grep '"event":"paris-rental-watch.pap.fetch.failure"'`
    surfaces every transient pap failure across all skills.
  * `will_alert` is informational; the actual decision is the return value
    of `evaluate_pap_alert(...)` in Section 6 (single source of truth so
    a SKILL.md drift can not cause a silent miss).
  * Newlines are collapsed → one failure = one log line, regardless of
    web-fetch's stderr (which may carry multi-line tracebacks).
  * Reason truncation cap: `REASON_MAX_CHARS = 300`.
  * Encoding: `ensure_ascii=False` — Korean / French diagnostics stay
    readable.

Escalation event (Section 6, fired only when consec ≥ threshold AND no
alert in last 24h):

  {
    "event":            "paris-rental-watch.pap.fetch.alert",
    "ts":               "<ISO 8601 UTC>",
    "consec_failures":  <int>,
    "reason":           "<truncated reason>"
  }
