================================================================================
Pre-fix issue: cf_detect.py false-positives on cleared post-bypass page
================================================================================
On a successfully bypassed pap.fr page the body still contained TWO benign
CF artefacts that triggered cf_detect false positives:

  1. URL-encoded analytics referer echo. Piano tracking URLs include
        href="…/redirect?ref=https%3A%2F%2Fwww.pap.fr%2F…%3F__cf_chl_tk%3D…"
     which has the URL-encoded form of the original CF challenge URL
     (with the token in a `ref=` query value). cf_detect.py's
     `__cf_chl_tk` / `cf_chl_opt` substring matchers fired on these
     echoes even though no active challenge was running.

  2. CF JavaScript Detection (JSD) telemetry script:
        <script src="/cdn-cgi/challenge-platform/scripts/jsd/main.js">
     Cloudflare injects this telemetry on EVERY page it fronts, including
     fully cleared post-bypass pages. The bare substring
     `/cdn-cgi/challenge-platform/` therefore was not specific to an
     active challenge.

Both made cf_detection.is_challenge=true on a real listings page,
violating AC sub-condition 3.

Fix (container/skills/web-fetch/cf_detect.py):
  - URL-shaped tokens (__cf_chl_tk / cf_chl_opt / cf_chl_jschl_tk /
    _cf_chl_managed_tk) now require at least one RAW (non-URL-encoded)
    occurrence before counting. URL-encoded analytics echoes are
    rejected by `_token_has_raw_occurrence` (lookbehind for `%[0-9a-f]{2}`).
  - `/cdn-cgi/challenge-platform/` now requires at least one occurrence
    NOT followed by a benign sub-path (`scripts/jsd/`,
    `scripts/invisible.js`). Real challenge sub-paths
    (`/h/g/…`, `/h/b/…`) still fire.

Test coverage added in container/skills/web-fetch/test_cf_detect.py:
  test_url_encoded_cf_chl_tk_echo_in_analytics_referer
  test_raw_cf_chl_tk_still_detected
  test_mixed_raw_and_encoded_token_still_detected
  test_cdn_cgi_jsd_telemetry_only_does_not_trigger
  test_cdn_cgi_real_challenge_path_still_fires
  test_cdn_cgi_jsd_telemetry_plus_real_challenge_fires

  Result: 36 cases pass (was 30); cf_detect.py --self-test 17 cases pass.
