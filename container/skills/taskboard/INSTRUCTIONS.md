# 任务看板操作指南

## 存储

每个群两个文件：

| 文件 | 用途 |
|------|------|
| `tasks.md` | 活跃看板（进行中 + 待办） |
| `tasks-archive.md` | 已完成任务归档（永久保留） |

从 agent 工作区访问路径：`./tasks.md` 和 `./tasks-archive.md`（即当前群目录下）

## 文件格式

### tasks.md（活跃看板）

```markdown
# 任务看板

## 进行中

- 🔵 [任务简述] — 补充说明 (开始: YYYY-MM-DD)

## 待办

- ⬜ [任务简述] — 补充说明 (创建: YYYY-MM-DD)

---
*最后更新: YYYY-MM-DD*
```

### tasks-archive.md（归档）

```markdown
# 已完成任务归档

## 2026-05

- ✅ [任务简述] — 补充说明 (完成: YYYY-MM-DD)
- ✅ ...

## 2026-04

- ✅ ...

---
*最后更新: YYYY-MM-DD*
```

归档按月分组，新的在前。永久保留，不删除。

## 操作

### list — 查看看板

1. 读 `tasks.md`
2. 如果文件不存在，告诉用户"当前没有任务"
3. 展示进行中和待办项，已完成项只显示最近 5 条

### add — 添加任务

1. 读 `tasks.md`（不存在则创建）
2. 解析用户意图，提取任务简述和补充说明
3. 写入"待办"区块，标记创建日期
4. 如果用户同时说了要开始做，放到"进行中"

### done — 完成任务

1. 读 `tasks.md`
2. 模糊匹配用户说的任务名（不需要完全一致）
3. 从 `tasks.md` 中删除该任务
4. 追加到 `tasks-archive.md` 对应月份区块，标记完成日期
5. 如果匹配到多个，列出让用户选

### remove — 删除任务

1. 读 `tasks.md`
2. 模糊匹配，确认后删除（不移到已完成，直接删）

### start — 开始任务

1. 把"待办"中的任务移到"进行中"
2. 同一时间"进行中"可以有多个（不像 TodoWrite 限制为 1 个）

### clean — 清理看板

1. 检查 `tasks.md` 中是否还有残留的已完成项（兼容旧格式）
2. 如有，全部迁移到 `tasks-archive.md`
3. `tasks.md` 只保留进行中和待办
4. 更新时间戳

### history — 查看历史

1. 读 `tasks-archive.md`
2. 按月展示已完成任务
3. 可指定月份过滤："上个月完成了什么"

## 与其他 Skill 联动

### kickoff 联动

kickoff 启动任务时，自动往看板加一条"进行中"任务，内容取自 kickoff 的任务名。

### wrapup 联动

wrapup 收尾时，自动把对应任务标记为"已完成"。如果有遗留问题，作为新的"待办"加入看板。

## 注意事项

- **不要过度管理**：看板是轻量工具，每条任务一行就够，不要写成文档
- **模糊匹配优先**：用户说"把 BI 那个标完成"就应该能匹配到"BI 案例库优化"
- **自动感知**：如果对话中产生了明显的待办事项但用户没说"加任务"，可以建议加入看板，但不要自动加
- **归档永久保留**：`tasks-archive.md` 不删除，按月分组，方便回顾"某个月做了什么"
- **活跃看板保持干净**：`tasks.md` 只有进行中和待办，完成即归档
