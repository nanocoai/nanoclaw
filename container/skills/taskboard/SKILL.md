# 任务看板

每个群一个持久化任务看板，跨会话可查。

## 触发时机

- 用户问"有什么待办"、"任务列表"、"看板" → **list**
- 用户说"加个任务 XXX"、"记个待办" → **add**
- 用户说"完成 XXX"、"XXX 搞定了" → **done**
- 用户说"删掉 XXX"、"去掉那个任务" → **remove**
- 任务启动（kickoff）时 → 自动 add
- 任务收尾（wrapup）时 → 自动 done + 归档
- 用户说"清理看板" → 清除已完成项

操作前先读 `INSTRUCTIONS.md`（与本文件同目录）获取详细指南。
