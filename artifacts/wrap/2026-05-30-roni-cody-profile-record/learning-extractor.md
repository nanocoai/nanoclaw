# Learning Extractor

What worked:
- Pixel-based recoloring preserved the original NanoClaw mascot shape, face, outline, and shading better than generating a new illustrated character.
- Roni and Cody are easiest to distinguish by body color while keeping the same NanoClaw visual language.
- Keeping accessory variants as separate files avoids overwriting the clean base avatar.

Final visual decisions:
- Roni: bright sky-blue NanoClaw mascot.
- Roni cloud variant: same sky-blue mascot, horizontally flipped, holding a clean white cloud in the raised claw.
- Cody: bright orange NanoClaw mascot.
- Cody MacBook variant: same orange mascot, with a small laptop moved toward the upper raised claw.

Avoid for future edits:
- Do not replace the NanoClaw mascot with a new robot or unrelated character.
- Avoid detailed internal cloud icons; the cleaner cloud silhouette was preferred.
- Do not overwrite base variants with accessory variants unless explicitly requested.
